Q7 / WHAT THEY BUILD

Small interface choices can dominate.

On MGSM, putting the answer before reasoning is associated with near-total failure. On MMLU the same habit is much less harmful.

Q8 / DESIGNER CHARACTER

Cost is a stronger signature than quality.

Nemotron-Super averages about 35 worker calls on both tasks. The test-score differences between designers are much smaller than this cost spread.

Q9 / WHAT PREDICTS QUALITY

Validation works — within limits.

Reported validation–test Spearman correlation among working, tested designs. Different subsets; descriptive, not a significance test.

01 / A robust local null

MMLU: noisy selection, little gain.

All eight intervals cross zero. The observed 63–68% validation peaks are compatible with selecting the best of 30 noisy designs on 128 questions.

The best-of-30 simulation was reported with the earlier panel, not rerun here.

02 / The comparator matters

MGSM: two gains, but over CoT-SC.

Qwen3.5-35B and self-designing Qwen3-30B beat Self-Consistency. Against the stronger Debate scaffold, neither shows a clear gain.

03 / Not a final campaign verdict

Pending is not zero.

Qwen3.5-27B's selected MGSM design has no test score in the local report. Other MGSM design tests are incomplete; one search stopped at 28 generations.

Scope: one search run per designer and task. These are local October 2026 experiments, not a reproduction of the original paper's GPT-3.5 scores. No clear improvement does not prove equivalence.

Q6 + Q7 / SILENT FAILURE

The agent can run and still be broken.

Code that compiles, a successful API response, and a correct answer are different milestones. The clearest failure pattern is task-dependent.

A / Association, not intervention

Output order is a plausible mechanism.

The static code analysis suggests that asking for an answer first can preempt useful reasoning. Logs do not retain worker replies, so actual token order has not been observed or experimentally manipulated.

B / Task dependence

The same habit is not equally costly.

Nemotron-Nano is answer-first in 29/30 MMLU designs. Other designers' answer-first MMLU designs score 50–59% on validation; Nano's MMLU failures were instead traced to parsing and voting fallbacks.

C / A withdrawn interpretation

The detector itself needed fixing.

An earlier parser missed output_fields= keyword arguments. The corrected split is 60 answer-first / 177 reasoning-first, not 89 / 149. The claim that gpt-oss-120b survived through Python expressions was withdrawn.

Four different places a run can fail

Do not mix model behavior, protocol fit, and missing evaluations into one failure rate.

01 / GENERATE

Syntax and output limits

First-shot unusable proposals are mostly Python syntax errors. Qwen3-30B's early 4,096-token cap truncated 42% of designer calls.

02 / ACCUMULATE

Context overflow

The first MMLU panel outgrew three designers' context windows. Expanded context finished those runs; Qwen3-14B still stopped at 28 MGSM generations.

03 / EXECUTE

Silent answer failure

Parsing fallbacks, voting, and field ordering can produce wrong answers without an exception. A healthy process is not a healthy design.

04 / EVALUATE

Timeout is not accuracy

Expensive MGSM test runs hit the one-hour cap. Batch 10 was queued with larger caps; no resulting scores are in the local evidence.

Q1 / A SCREEN, NOT A FINAL TEST

Scaffolding headroom is task × worker.

Hand-designed seed agents before any search: 128 validation questions, one pass. The best seed is the best observed score, not a held-out selected winner.

Screening evidence only. Single-agent uncertainty is roughly ±8 points. The MGSM production baseline for Qwen3-30B is 78.8% over five repeats, not this screen's 74.2%. Do not combine the two protocols.

Why Qwen3-30B for MGSM?

Five of six alternative seeds exceed CoT by at least 5 points; the best gains 14.1 points. This offered broad scaffold headroom and a useful self-design condition.

DROP is not universally flat.

Qwen3.5-27B's best seed gains 6.9 F1 points; Mistral gains 5.3. But benefits are less widespread than in math, so the local campaign did not prioritize a DROP search panel.

Modern strength alone is not enough.

Phi-4 and Nemotron-Nano show little ≥5-point seed headroom in this screen. Conversely, a mid-strength Qwen3-30B worker improves substantially on MGSM.

Interpretation rules

No test-set cherry-picking

Modern contrasts refer to the validation-selected design, not each run's best test score. Validation ties are explicitly flagged.

No fabricated uncertainty

Forest bars use the report's paired bootstrap intervals. Elsewhere, points are point estimates unless labeled. No intervals are computed from rounded table values.

No causal size or field-order claims

One run per designer supports descriptive signatures. The field-order split is observational and confounded with designer behavior.

A source inconsistency stays visible

The MGSM prose says four selected designs are significantly below Debate. The printed table has five wholly negative intervals, including Nemotron-Nano. This explorer follows the table and does not silently change the report.
